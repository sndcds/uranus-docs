An **event type** is a top-level category. Its **genres** provide more specific
classifications within that category. IDs are shown exactly as returned by the
API; some event types have no associated genres.

Select a language for the names, or search by name or ID. Data is loaded when
you open this page; use **Reload data** to fetch the latest values again.
