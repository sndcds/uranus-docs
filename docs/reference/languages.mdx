Browse the languages that can be selected in Uranus. Each language is listed
with the code returned by the API. Codes made only of lowercase letters appear
first; codes containing other characters are grouped below them as special
languages.

Choose the language used for the language names, or search by name or code. The
list is loaded from the API when you open this page; use **Reload data** to get
the latest values.
